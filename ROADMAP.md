# GeoChannel Roadmap

GeoChannel is currently focused on making the existing spatial streaming data
plane reliable, understandable, and straightforward to operate.

## Current Priorities

- Stable versioned API and JavaScript packages
- Reproducible local and controlled deployments
- OpenAPI documentation and contract testing
- Replay, reconnect, backpressure, and quota reliability
- Operational guidance based on real deployment experience
- External integration feedback from live-map teams

## Later, Based on Demonstrated Demand

- Additional producer integrations
- Longer retention and durable downstream consumption
- More aggregation contracts
- Deployment templates for common infrastructure providers
- Additional client languages
- High-availability and multi-region operating patterns

## Explicit Non-Goals for the Current Preview

- Fleet, routing, device-management, or geofencing application features
- General-purpose stream processing
- Historical geospatial analytics
- Self-service billing and cloud provisioning
- Unbounded scale or production SLA claims

Roadmap items are not commitments. Substantial proposals should begin with a
GitHub issue describing the use case and compatibility impact.
