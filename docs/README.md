## Documentation Rules

- Describe current behavior before future plans.
- Keep endpoint details in [API.md](API.md).
- Keep operational procedures in runbooks and checklists.
- Use relative links and verify commands against a fresh clone.
- Do not add customer credentials, customer-identifying information, pricing,
  proposals, or private deployment details.
