# Support

## Community Support

- Use GitHub Discussions for design and usage questions.
- Use GitHub Issues for reproducible defects and scoped feature requests.
- Use private vulnerability reporting for security issues.

Community support is best effort and has no guaranteed response time.

## Managed Support

Teams evaluating a production live-map workflow can request a managed,
single-tenant design-partner deployment. See
[docs/MANAGED_SERVICE.md](docs/MANAGED_SERVICE.md).
