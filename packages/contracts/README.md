# `@geochannel/contracts`

Shared TypeScript declarations, constants, and runtime guards for GeoChannel
API payloads and stream frames.

```js
import {
  STREAM_OFFSET_LIVE,
  isStreamFrame
} from "@geochannel/contracts";
```

See the
[API reference](https://github.com/zamo24/geochannel/blob/main/docs/API.md)
for protocol details.
